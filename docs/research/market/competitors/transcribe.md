# Competitor teardown: Transcribe! (Seventh String Software)

## TL;DR
- Transcribe! is a desktop assistant for manual transcription: slow down (1/20x to 2x without pitch change), fine-tune and shift pitch (up to three octaves), unlimited named loops, waveform with markers, a spectrum view with note/chord "guessing", and video display.
- One-time purchase of $39 (volume discounts down to $15), 30-day free evaluation, keys work on Windows, Mac and Linux; no phone/tablet version, no subscription.
- It does not separate stems or auto-transcribe: it supports a human ear. The page itself says you still need your ear to judge which spectrum peaks are real notes.
- Splitune takeaway: a pure "assist the human transcriber" tool has survived for decades at $39; its feature set (loops, markers, spectrum, piano-roll guesses) is the proven minimum for manual verification UIs.

## Findings

### Core features
Slow-down from one twentieth to double speed with pitch preserved; tuning in cents and shifts up to three octaves; transposition for transposing instruments; any number of named loops that can be saved/recalled; scrollable waveform with section/measure/beat markers; spectrum view of a selected note or chord with "note guessing" and "chord guessing" (piano-roll display of guesses); video display for most video files; EQ, mono/karaoke mixing, pedal support ([Transcribe! overview](https://www.seventhstring.com/xscribe/overview.html)). MIDI files are not handled because it works on audio samples ([Transcribe! overview](https://www.seventhstring.com/xscribe/overview.html)).

### UX flow of the "learn a song" path
Open an audio/video file → set markers and loops → slow down → select a note in the waveform and read the spectrum/guess → write notation elsewhere. The product helps you derive notes; it does not teach or score.

### Instruments and levels
Instrument-agnostic; aimed at transcribers (musicians, teachers).

### Pricing and business model (accessed 2026-10-20, [buy page](https://www.seventhstring.com/xscribe/buy.html))
- 1 copy $39; 2-4 copies $31 each; 5-19 $25; 20-99 $20; 100+ $15 (USD, plus tax).
- A single license covers one computer, or up to three if for your exclusive use; keys do not expire; 30-day free evaluation ([buy page](https://www.seventhstring.com/xscribe/buy.html)).
- Perpetual license; updates to the current version are free per the vendor.

### Platforms (official)
Windows, Mac and Linux; not phones or tablets ([buy page](https://www.seventhstring.com/xscribe/buy.html), [overview](https://www.seventhstring.com/xscribe/overview.html)).

### What is public about tech and company
Single-developer shop (Seventh String Software); no ML claims. The "guessing" features are signal analysis aids, not neural transcription. No engineering blog.

### Standout strengths
Low price, perpetual license, simple and focused workflow, long track record.

### Common complaints (tier 4)
We did not find independent complaint sources we could open; the vendor's own "reviews" page is self-curated and not usable as evidence. Gap noted.

### What Splitune can learn or do differently
- Provide a "verify" view (waveform + markers + note guesses) so the learner can sanity-check machine output.
- Offer a one-time purchase option for hobbyists; the segment tolerates $15-$40 tools.
- Automate the part Transcribe! leaves to the ear, but expose confidence so users can trust-check.

## Implications for Splitune
Establishes the price floor for a pure transcription-assist utility (about $39 one-time) and the feature baseline for manual correction tools.
