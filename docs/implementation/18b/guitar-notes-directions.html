A · Tab lanes into the neck (recommended)

  • Tab's own geometry: string = row (string 1 on top), time runs left to right, fret = the number. Practising here builds the skill used to read the Tab view and real tab.
  • Strings continue from the neck into the lanes, so each note lands on its own string. The neck lights the fingers now and shows the next shape as dashed ghosts.
  • One bar of look-ahead at full reading size (36 px at Stand, about 700 px wide on a tablet; 24 px across about 500 px on a phone).
  • Phone landscape works once the chord strip folds into the status bar: six 30 px lanes.
  • Strums read as one stacked shape, like tab. Bass gets taller lanes.
  • Closest precedent: Yousician's main view (horizontal, tab order, notes move right to left).

B · Chord-box fall

  • Same metaphor as piano's roll, and the box below is the chord-diagram layout learners already know. So the two instruments would feel like one product.
  • Look-ahead runs along the short axis: about 270 px for 0.9 bar on a tablet. Strummed 16ths stack into towers of overlapping numbers.
  • Phone landscape is unusable: the box gets about 50 px.
  • Reading direction (down) doesn't match tab (across). No 2D guitar product found that uses it.

C · 3D highway (reject)

  • Perspective shrinks what's ahead. With depth 3, digits reach the 18 px floor (26 §6.3) only 0.67 bar out, and 2 bars out they are 9 px at Stand.
  • Spacing that changes with depth makes timing hard to judge. That's the main player complaint about Rocksmith's view, and Ubisoft ships a 2D tab view as an accessibility alternative.
  • Frame budget isn't the problem (it's the same canvas work as B); readability is.

Shared by every direction

  • Position is a pure function of the audio clock, read once per frame. The neck window is also a function of time, so re-framing is eased (400 ms, standard easing) but exact on seek.
  • Past the loop end the next pass is already drawn, so the wrap never blanks (try “Loop bars 24–27”).
  • Confidence: dashed outline, uncertain ink, “?” on low notes. Unplayable notes get 8va/8vb or “!”, never dashes.
  • Strings are told apart by position and name, never colour. The guitar or bass hue is only the note tint and tails, with the ink outline carrying contrast. Finger dots are ink, like chord diagrams.
  • Landing acknowledgement: a small ring, at most 3 per second, off with reduced motion. Reduced motion pages a bar at a time and moves only the playhead.
